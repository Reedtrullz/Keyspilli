# Source and delivery contracts

Use the selected checkout's implemented validators and actual returned fields.
These rules do not create a new command, receipt or musical authority.

## Exact source authority and repairs

Keep original authorized bytes, source identity and hashes. A self-authored
fixture or candidate-derived transcription is not independent source truth.
Human validation applies only to the exact reviewed labels and scope.

Version-2 source validation binds source identity, timebase, clock, intervals,
roles, pitches, attacks, durations, required/ambiguous flags and occurrences.
Changing one requires fresh legitimate evidence; never edit a genuine receipt.
Version-1 receipts remain historical observations and do not acquire repair
authority. Software delivery/Player equality and advisory model findings cannot
authorize unsupported source-note changes.

A repair needs a unique exact target and expected source event, both pinned by
the host. A reviewed note at 0 seconds cannot authorize another at 1 second.
Ambiguous, altered or stale targets remain blocked. If this checkout cannot
provide the current exact authorization contract, keep repairs advisory and
continue independent supported operations. Use its source-validation and
score-review procedures; do not assemble an authorization object manually.

## Preservation and clocks

Keep source notes separate from reductions. The import allocator preserves
valid earlier history before a later density conflict while retaining sounding
limits; the cut tail is not reconstructed. `sourcePreparation`, when returned,
records sanitation, quantization/deletion, duration and octave preparation with
source origins. It covers preparation before difficulty reduction. It is not a
complete per-tier change ledger or an exact Source-profile guarantee. Compare
protected events in each delivered variant; source-origin counts alone are
insufficient. Accepted reference hashes are never repinned to fit new output.

Retain source-score measure coordinates and native elapsed seconds separately.
Pickups, terminal rests, meter changes and tempo segments require the correct
map for the consumer. A scalar playback beat clock is not interchangeable with
the source score after tempo normalization. Use verified notation/navigation
maps where available; do not infer shared timing from equal beat numbers.
Unsupported timing remains an explicit limitation, not a guessed offset.

## Formats and resolved events

MusicXML transposition, octave-shift and nonzero performance offsets require
the host's explicit unsupported result or verified sounding-pitch support.
For refusal, obtain concert-pitch notes or a correctly rendered MIDI performance.
Removing a transpose declaration alone is not conversion. Preserve raw bytes.
For MXL, use the declared first score in `META-INF/container.xml`; never select a
companion after the declared source fails. A missing declared score is a source
error. Legacy archives without a container must identify one unambiguous score.
Warnings about dynamics, wedges, articulation or ornaments identify omissions.
`artifactFidelity` distinguishes symbolic event checks from expressive fidelity;
MusicXML currently omits velocity/dynamic marks even when MIDI retains velocity.

Verify actual resolved Chords notes, attacks and releases, not labels alone.
Held supported seventh/suspended/diminished stacks must cover their real support
interval; do not add repeated strikes to hide gaps or sustain across releases.
Check C/E-style bass/upper-tone hand assignments and Both/L/R selections through
reparsed exports. Apply transposition once. Sample tails, timbre and mixer levels
are acoustic settings, separate from symbolic key releases and hand assignment.

## Readiness

Record source evidence, six-variant event checks, actual resolved playback,
second isolated import, exports, preview hashes and limitations per mode. A
bounded diagnosis or valid artifact is software evidence. Useful provisional
output is deliverable with its precise gaps; it is not independent musical
qualification or permission to publish.
