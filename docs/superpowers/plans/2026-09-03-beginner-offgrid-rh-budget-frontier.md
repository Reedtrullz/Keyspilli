# Beginner off-grid interior RH budget frontier

## Objective

Run a diagnostic-only product-contract experiment for the Cover Very Easy →
Beginner RH identity cliff. Test a frozen baseline plus exactly two generic
counterfactual envelopes: at most one, then at most two, structurally
supported off-quarter-grid RH attacks per source-meter window. Keep current
Beginner density, IOI, range/span/jump, maxSim<=2, and sparse-LH behavior
unchanged. Do not change production generation unless Candidate A passes the
explicit promotion gate.

## Tasks

1. Freeze branch/output/disk state and reuse `cover-rh-cliff.ts` lineage,
   identity, and playability evidence; confirm fresh Classical/Cover/Pop
   baseline.
2. Add a pure, deterministic frontier evaluator and synthetic tests. Define
   generic off-grid eligibility from existing structural signals, meter windows
   (4 beats in 4/4; 4.5 in 9/8), one/two-per-window budgets, LH collision
   blocking, and explicit timing-complexity metrics. Do not wire it into
   generation.
3. Run the frozen baseline/A/B frontier on all three fixtures, including
   public Beginner→Easy separation and blocked-by-current-LH accounting.
4. Select exactly one decision from the brief, write a path-free report and
   deterministic JSON, and record `NO_MUSICAL_BEHAVIOR_CHANGE` unless the
   preregistered Candidate-A gate is fully met.
5. Verify focused/full tests, all workspace typechecks, diff hygiene,
   deterministic rerun, unchanged production digests, remote parity, and disk;
   log the result in the Keyspilli Obsidian project note.

## Constraints

- No Cover-specific rules, note lists, threshold shopping, reference MIDI,
  audio, human audit, upstream research, deployment, or public-ladder/LH
  policy changes.
- Candidate A/B are diagnostic counterfactuals only unless the exact Candidate
  A promotion gate is met; Candidate B is never promoted.
- Frozen eligibility: a RH event in the existing `beginner-ladder` rejected
  set, with a Very Easy/source start more than `0.01` beat from the `0.25`
  Beginner grid, one-to-one ancestry, and at least one existing generic signal:
  phrase boundary (gap `>1.5` beats), local extremum, same-pitch reattack,
  absolute neighbor leap `>=7` semitones, velocity at/above the existing
  75th-percentile cut, or duration at/above the existing 75th-percentile cut.
  Same-onset secondary voices and candidates without ancestry are excluded.
- Frozen selection: rank eligible events by number of distinct signals
  (descending), then phrase-boundary/extremum/reattack/leap/high/long flags,
  then start, MIDI, and stable ancestry key. Select at most one (A) or two
  (B) per source-meter window, using `4` beats for 4/4 and `4.5` for 9/8.
- A/B retain the candidate's original Very Easy/source onset and all baseline
  LH notes. Reject an addition if it violates maxSim `2`, Beginner density or
  median-IOI limits, piano range/span/jump checks, or the unchanged LH
  sounding envelope; classify the first blocking constraint instead of
  retiming or moving another event.
- Keep generated report artifacts outside the repository except compact,
  path-free documentation/JSON.

## Candidate-A promotion gate (frozen before evaluation)

Candidate A may be considered for implementation only if it recovers at least
50% of Candidate B's structurally significant event recovery, preserves the
exact Beginner LH event set and all frozen playability constraints, remains
clearly below the existing Easy complexity envelope, and produces no material
densification or identity regression on Classical or Pop. Candidate B is
diagnostic-only in all cases. If any condition is unmet, record the applicable
decision and keep musical behavior unchanged.
