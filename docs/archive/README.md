## Reproduce an old review

Download the archive and checksums, verify with `shasum -a 256 -c SHA256SUMS`, then extract into a separate empty directory. Original relative paths and manifest contents are preserved. Historical scripts and manifests that expect removed media should be used with the complete matching source snapshot at tag `archive/repository-evidence-2026-09-27`, not overlaid on a working catalog. GitHub's Source code download supplies that complete snapshot.
